The objectives of this assignment are to (1) use non-linear least square estimation and non-linear gradient descent in building an algorithm for Single Point Positioning using the measurements from a Global Navigation Satellite System (2) analyze and predict student depression levels using logistic regression (3) construct two types of neural networks(multi-layer perceptron (MLP) convolutional neural network (CNN)) to read handwriting using the MNIST dataset and to compare their performance.
